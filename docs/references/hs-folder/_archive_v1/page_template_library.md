# Page Template Library

This library defines reusable interior page templates for the recovery coloring book catalog.

## TPL-01 Solo Portrait Calm Scene
- Use for one-person healing moments.
- Best scenes: journaling, tea, breathwork, quiet rest.
- Keep the focal person dominant and the background supportive.

## TPL-02 Support Circle Scene
- Use for meetings, family support, peer encouragement.
- Keep group size readable and emotionally clear.
- Background should never overpower the people.

## TPL-03 Quote Page Framed Border
- Use for affirmations and bilingual quote pages.
- Leave generous white space around text.
- Border motifs should feel seasonal, not crowded.

## TPL-04 Healing Room Interior
- Use for bedrooms, living rooms, reading corners, meditation spaces.
- Focus on restful objects and strong furniture silhouettes.
- Keep wall and floor patterning restrained.

## TPL-05 Symbol Cluster Page
- Use for motif-only pages and pacing resets.
- Group objects with clean separation for easy coloring.
- Avoid turning the page into a dense mandala.

## TPL-06 Walking Reflection Scene
- Use for outdoor grounding and recovery-walk pages.
- Keep paths, sidewalks, and sky areas open enough to color easily.
- Use seasonal foliage to differentiate versions.

## TPL-07 Porch or Patio Conversation
- Use for intimate 2-3 person support scenes.
- Great for family, mentors, and friendship pages.
- Keep furniture and setting simple enough to preserve readability.

## TPL-08 Window + Journal Reflection
- Use for quiet indoor reflection scenes.
- Combine comfort objects with a simple exterior view.
- Strong option for all four seasons.

## Library rules
- Rotate template types across each 15-page book for emotional pacing.
- Never place two dense pages back to back.
- Every book should include a mix of people, spaces, and quote-driven pages.
- Seasonal swaps should change props and atmosphere without changing the core layout logic.
