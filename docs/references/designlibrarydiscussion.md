## Prompt-writing standard

For every `AI Design Prompt`, use this formula:

**Phrase + design subject + visual elements + style + color direction + print requirements + exclusions**

Example:

> Create a print-ready T-shirt graphic featuring the phrase “[TEXT].” Include [VISUAL ELEMENTS]. Use [DESIGN STYLE] with [COLOR DIRECTION]. Make the lettering easy to read and the artwork suitable for DTF or screen printing. Use a transparent background. No shirt mockup, no model, no watermark, no extra text.

For image generation, it helps to always specify **transparent background**, **print-ready**, **centered composition**, **no mockup**, and **no watermark** so the model is generating artwork rather than an advertisement or product photo. That is consistent with the internal asset-generation system you’ve been considering: prompts, templates, review, storage, and export in one repeatable workflow. [^1_1]
